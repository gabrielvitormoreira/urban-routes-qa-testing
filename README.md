# 🚕 Urban Routes - QA Testing Project

## 📌 Project Overview

This project was developed during the **QA Analyst Bootcamp at TripleTen**.

The main objective was to validate the functionality and usability of the Urban Routes application through manual testing processes, identifying potential defects and documenting test results.

---

# 🎯 Testing Objectives

The goal of this project was to ensure that the application functions according to expected requirements by performing:

- Functional testing
- Regression testing
- Test case creation
- Bug identification
- Test documentation

---

# 🧪 Testing Process

The following activities were performed:

✅ Analysis of application requirements

✅ Creation of test scenarios

✅ Development of test cases

✅ Execution of manual tests

✅ Identification of unexpected behaviors

✅ Documentation of bugs found

---

# 📋 Test Cases

Test cases were created to validate:

- User interactions
- Application functionality
- Input fields
- Expected versus actual results

Tools used:

- Google Sheets / Excel

---

# 🐞 Bug Reports

During testing, identified defects were documented with:

- Bug description
- Steps to reproduce
- Expected result
- Actual result
- Severity level
